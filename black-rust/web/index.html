black-battle playground

Each panel calls functions ported from Pokémon Black's overlay 93 (battle_calc.s), running here as WebAssembly. Each result comes from a single ported function. The full damage pipeline (STAB, the 85–100% random roll, the crit multiplier, abilities, items) is not ported yet, so no final damage number is shown.
